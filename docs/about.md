# About Me

With years of experience in backend engineering and system architecture, I've worked on problems ranging from real-time data processing at scale to designing microservices that power production systems. I believe in writing code that's not just functional, but maintainable and well-documented.

- **Elegance**: Simple, clean solutions to complex problems

- **Collaboration**: Great things happen when teams communicate clearly
