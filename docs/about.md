# About Me

I'm a curious engineer with a passion for building scalable, elegant systems. My expertise spans distributed systems, data pipelines (streaming and batch) and cloud infrastructure. 

## Background

With years of experience in backend engineering and system architecture, I've worked on problems ranging from real-time data processing at scale to designing microservices that power production systems. I believe in writing code that's not just functional, but maintainable and well-documented. During my career as software engineer, I learnt and used different languages (Java, Scala, Python, Typescript), but the ones built on JVM are preferred. In the future, my interests will be oriented over new tools like Go or Rust. 

## What Drives Me

- **Curiosity**: Understand how a system works, how to improve it?
- **Scalability**: How do we build systems that gracefully handle growth?
- **Elegance**: Simple, clean solutions to complex problems
- **Learning**: Every project is an opportunity to expand my toolkit
- **Collaboration**: Great things happen when teams communicate clearly
